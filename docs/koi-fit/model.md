# Онтологическая модель КОИ в прототипе

На главном экране выберите преподавателя. Ветви карты показывают дисциплины, практики и ВКР, связанные с ним в открытых материалах. Нажатие на объект открывает участников, их роли, источник и результаты проверок. Нажатие на имя участника открывает его связи в тех же материалах. Период возле объекта означает год документа.

## Решения моделирования

Каждый преподаватель имеет постоянный идентификатор. Участие связывает человека, объект, роль, организацию и документ. В приказе 2018 года две записи о Д. Е. Пальчунове отличаются организацией. Обе ссылаются на один узел преподавателя. На титуле ВКР роли заведующего кафедрой и руководителя работы принадлежат разным людям. Связи с дисциплинами описывают авторство программы, чтение курса и назначение в группу по отдельности.

Общая модель включает три дисциплины, одну практику и одну ВКР. Четыре архивных источника разобраны в [исследовании КОИ](README.md). Пятый источник — [сообщение НГУ о хакатоне 2025 года](https://t.me/s/nsuniversity/7114). Оно связывает Г. Э. Яхъяеву с курсом «Логические основы программирования» как лектора. Сведений о назначении в конкретную группу в этой публикации нет.

[Общий граф RDF/OWL](../../model/koi.ttl) содержит классы, свойства, экземпляры, даты и ссылки на документы. [Запрос SPARQL](teacher.rq) для Д. Е. Пальчунова возвращает четыре участия в трёх объектах. Для сравнения можно заменить идентификатор на `k:yakhyaeva` или `k:rylov`. В прототипе прикладные правила исполняет JavaScript. Для дат условие имеет вид `фактическая дата ≤ срок`; при неизвестной дате результат также неизвестен. Для назначения проверяется наличие участника в конкретной роли. Явное отсутствие даёт нарушение, пропуск данных — неопределённый результат.

## Воспроизводимые сценарии

| Объект | Условие проверки | Ожидаемый результат |
| --- | --- | --- |
| Практика, 2018 | Открыть источник и сравнить стороны | П1.1 и П1.2 выполнены. У одного человека две роли |
| Та же практика | В сценарии у руководителя от организации выбрать «Нет сведений», затем «Явно указано отсутствие» | П1.2 меняется с неопределённого результата на нарушение. П1.1 остаётся выполненным |
| ВКР, 2022 | Открыть документальные данные, затем указать в сценарии фактическую сдачу 20 и 21 мая 2022 года | В2 последовательно даёт «Недостаточно данных», «Выполнено», «Нарушено» |
| Та же ВКР | В сценарии в поле текста ВКР указать «не приложен» | В3 выдаёт нарушение независимо от дат |
| Дисциплина | Посмотреть автора программы или лектора, затем указать группу и назначить её преподавателя в сценарии | Д1 меняется с «Недостаточно данных» на «Выполнено», преподаватель видит связь с дисциплиной |

Сценарий хранится в памяти открытой вкладки. Его можно сбросить или скачать в Turtle. Изменённые утверждения в выгрузке имеют отдельное основание. Личные карточки по четырём типам процессов доступны в соседнем разделе. Общая выборка КОИ содержит документированные участия. Для учебных поручений конкретной группы в неё ещё предстоит внести обезличенный первичный документ.

Формальные требования, сценарии с заранее заданными несоответствиями, ручной ввод в сценарии и результаты проверок реализуют соответствующие части тезиса. Набор источников охватывает отдельные годы и процессы. Экспертную оценку представителем кафедры предстоит провести отдельно. Правила прототипа доступны для обсуждения с экспертом.

Запуск проверок из корня проекта: `npm test`. Команда `npm run ontology` воспроизводит обе выгрузки в каталоге `model/`.

При проверке 11 ноября 2026 года RDFLib прочитал 258 троек документальной версии. Запрос по идентификатору преподавателя вернул четыре строки для Пальчунова, две для Яхъяевой и одну для Рылова. В браузере проверены переходы между участниками, изменение одной стороны практики, просрочка ВКР и назначение в группу. Скачанный из браузера граф сценария содержал тестовую дату сдачи со ссылкой на сценарий как основание.
